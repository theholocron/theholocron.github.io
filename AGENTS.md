## What this repo is

The main documentation site for the `theholocron` org, built with Astro and
Starlight. Deployed to `https://docs.theholocron.dev/` via GitHub Pages.

Content is loaded from six docs packages published by other org repos:
`clients-docs`, `configs-docs`, `holocron-docs`, `skills-docs`, `themes-docs`,
`utils-docs`. Each package maps to `/projects/<repo>` in the URL and sidebar.

## Architecture

- **Flat Astro site** — not a monorepo. A single `package.json` at the root.
- Content loaded at build time via `createDocsLoader` from
  `@theholocron/docs-theme/loader` in `src/content.config.ts`.
- Sidebar auto-generated by Starlight from the `projects/` slug prefix.
- No compilation step — type checking via `pnpm typecheck` (`astro check`).
- Deploy: the custom `deploy.yml` workflow handles the GitHub Pages deploy
  directly (the `deploy-docs` reusable workflow targets monorepos with
  `<name>-site` packages and cannot be used here).

## Quality

- `pnpm build` — full Astro build to `dist/`.
- `pnpm typecheck` — `astro check` across all `.astro` and `.ts` files.
- `pnpm lint` — ESLint via the `lint.yml` workflow.
- No test suite (content site with no logic to unit test).
