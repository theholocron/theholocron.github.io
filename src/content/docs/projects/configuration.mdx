A monorepo containing all of our shareable configuration files.

- [browserslist-config](https://github.com/theholocron/holocron/blob/alpha/configs/browserslist-config/README.md) - A [Browserslist](https://browsersl.ist) configuration for all browsers and devices supported.
- [commitlint-config](https://github.com/theholocron/holocron/blob/alpha/configs/commitlint-config/README.md) - A [CommitLint](https://commitlint.js.org) configuration for writing Git commits.
- [eslint-config](https://github.com/theholocron/holocron/blob/alpha/configs/eslint-config/README.md) - [An ESLint](https://eslint.org) configuration for writing well-formed Javascript.
- [lint-staged-config](https://github.com/theholocron/holocron/blob/alpha/configs/lint-staged-config/README.md) - A [Lint Staged](https://github.com/lint-staged/lint-staged) configuration for linting code that has been staged in Git.
- [prettier-config](https://github.com/theholocron/holocron/blob/alpha/configs/prettier-config/README.md) - A [Prettier](https://prettier.io) configuration for formatting libraries.
- [tsconfig](https://github.com/theholocron/holocron/blob/alpha/configs/tsconfig/README.md) - A [TypeScript](https://www.typescriptlang.org) configuration for checking types.

## 📦 Installation

The following pattern will install any package; swap out `<lib>` for anyone of the packages listed below to install.

```sh
pnpm add --save-dev @theholocron/<lib>
```

## 🧪 Usage

Check the README for each configuration within the `packages` directory for specific usage instructions.
